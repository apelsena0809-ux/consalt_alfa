# Альфа-Курс — персональные рекомендации и библиотека материалов

## Запуск на Python 3.15 (Windows)

1. Установите Python 3.15 x64.
2. Распакуйте архив и откройте папку `alfa_course_ui`.
3. В адресной строке Проводника введите `cmd`.
4. Выполните команды:

```cmd
py -3.15 --version
py -3.15 -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Откройте `http://localhost:8501`. Остановка — `Ctrl+C`.

## Запуск через Docker

```cmd
docker compose up --build
```

Откройте `http://localhost:8501`. Остановка:

```cmd
docker compose down
```

Dockerfile использует `python:3.15-slim`, зависимости — Streamlit 1.67.0.

## Что есть в приложении

- Онбординг: стадия бизнеса, сфера, задача и опыт.
- Персональная подборка из каталога по скорингу: 0,5 за совпадение задачи, 0,3 за стадию, 0,2 за сферу и бонус 0,05 за отмеченные материалы.
- Объяснение рекомендации и следующий шаг.
- Отдельная библиотека с поиском и фильтром по теме.
- Прямые кликабельные ссылки на страницы первоисточников; ссылка открывается через кнопку «Открыть материал ↗» или заголовок карточки.
- Кнопка «Отметить изученным» и история в профиле.
- Каталог: `data/processed/materials.csv` (24 материала). Чтобы добавить ресурс, внесите строку с уникальным `id`, темой, описанием и полной ссылкой `https://...`.

## Источники и актуальность

Каталог содержит внешние ресурсы: ФНС России, МСП.РФ, «Мой бизнес», Яндекс Бизнес, образовательные разделы Ozon и Wildberries, ЕИС закупок, Росстат и другие. Содержание и условия на внешних сайтах могут изменяться; для налоговых, правовых и регуляторных решений сверяйтесь с актуальной информацией на сайте ведомства и учитывайте регион.

## Структура

- `app.py` — интерфейс Streamlit.
- `src/integration.py` — загрузка каталога, ранжирование и объяснения.
- `data/processed/materials.csv` — библиотека внешних материалов.
- `Dockerfile`, `compose.yaml` — контейнерный запуск.

История изученных материалов хранится в `st.session_state` и сбрасывается после завершения пользовательской сессии.
